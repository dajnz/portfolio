Доступность — это не чек-лист, который прогоняют один раз перед запуском. Это набор ограничений, благодаря которым интерфейс работает для всех, включая клавиатуру и скринридеры.

## Начните с семантичного HTML

`div`, стилизованный под кнопку, — кнопка только для мыши. Используйте элемент, несущий смысл, и поведение приложится.

```html
<button type="button" @click="submit">Отправить</button>
<!-- не: <div class="button" @click="submit"> -->
```

> [!IMPORTANT]
> Первое правило ARIA — не использовать ARIA, когда нативный элемент уже справляется.

## Фокус — это функция

Каждый интерактивный элемент должен быть достижим и виден при фокусе. Удаление обводки фокуса без равнозначной замены — регрессия.

| Элемент | Поведение клавиатуры |
| --- | --- |
| Модалка | захват фокуса, возврат при закрытии |
| Меню | стрелки, `Escape` закрывает |
| Форма | логичный порядок табуляции |

## Проверяйте в CI

Автоматические проверки ловят большую часть проблем. Они не заменяют ручное тестирование клавиатурой и скринридером, но останавливают регрессии.

```bash
npx axe --exit public/
```

> [!TIP]
> Провалы контраста легче всего поймать автоматически и легче всего исправить в дизайн-токенах.

## Относитесь к этому как к качеству

Доступные интерфейсы обычно лучше: понятнее иерархия, предсказуемый фокус, честные подписи.
