Современный PHP — не другой язык по сравнению с доставшимся вам легаси. Это тот же язык, но с большей дисциплиной: строгие типы, небольшие объекты и явные границы.

## Строгие типы везде

`declare(strict_types=1)` превращает тихое приведение в громкую ошибку на границе. Именно там это и нужно.

```php
declare(strict_types=1);

final readonly class Email
{
    public function __construct(public string $value)
    {
        if (filter_var($value, FILTER_VALIDATE_EMAIL) === false) {
            throw new InvalidArgumentException('Invalid email.');
        }
    }
}
```

> [!IMPORTANT]
> Сущность, защищающая свои инварианты, нельзя перевести в невалидное состояние небрежным вызовом.

## Замените «массивозный суп» объектами

Ассоциативный массив, проходящий через пять слоёв, прячет контракт. Именованный объект его документирует и позволяет помочь проверке типов.

| Вместо | Используйте |
| --- | --- |
| `['id' => 1, 'sum' => 100]` | `Money`, `InvoiceId` |
| `string $status` | enum `InvoiceStatus` |
| возврат `null` | исключение или пустой объект |

## Зависимости направлены внутрь

Доменный код не должен импортировать фреймворк. Когда импортирует, правила становятся невозможными для изолированного тестирования.

> [!TRADEOFF]
> Больше типов — больше кода на старте. Награда в том, что рефакторинг становится ошибкой компилятора, а не поиском сокровищ.

## Внедряйте постепенно

Не обязательно переписывать легаси-систему. Проведите границу, сделайте новый код строгим и дайте старому сокращаться.
