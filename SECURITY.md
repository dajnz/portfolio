# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Security fixes are applied there
and are not backported to older commits or tags.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting:

1. Open the [Security tab](https://github.com/dajnz/portfolio/security) of this
   repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version or commit, and the steps to
   reproduce it.

Do not open a public issue for a security report. You will receive an
acknowledgement in the advisory thread, and the fix will be coordinated there.
